# Specification quality checklist

- [x] User-confirmed actor, trigger, outcome and invariants recorded.
- [x] Default workflow is the first acceptance gate.
- [x] Stable requirement IDs with separated types and populated statuses.
- [x] Real observable issue scenarios, refusal cases and positive controls.
- [x] Withdrawal, stale observation and concurrent-start coordination are distinct.
- [x] No unresolved product questions or implicit exactly-once promise.
- [x] Ordinary software change, not a terminology/bulk-edit migration.
