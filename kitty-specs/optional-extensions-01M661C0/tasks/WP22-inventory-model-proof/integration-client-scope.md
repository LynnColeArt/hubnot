Root implementation decision, 2026-10-31, before WP22 final validation. The owner found unvalidated typed success/error paths in the drafted inventory consumer, including unapproved convenience inspect/search actions. The approved host contract requires complete typed response validation before another request.

Keep the inventory executable focused on its actual identity.public, artifact.type.publish and artifact.mutate calls for publishing, creating, revising, resolving and converting the three independent inventory shapes. Remove the drafted consumer-specific inspect/search convenience actions and their advertisements rather than ship unchecked response paths or invent a general SignedArtifact/schema client SDK. Fully validate the remaining complete envelopes, correlation, success data and error values; terminal null-ID responses stop the session. Preserve definitive error/recovery/operation semantics.

This does not remove task coverage: T090 explicitly requires plugin-free filters, bounded regex, exchange and independent clone reconstruction across the charter/inventory corpora. Retain those actual generic CLI journeys, exact IDs, all missing-dependency/shape controls and the actual host shape-search fixture where required. T088–91 still require the standalone model, both actors, all three shapes, conflicts/resolution/evolution, inertness, consumer removal and public/private boundaries. No production core or frozen contract change and no coverage completion is claimed by this choice. Final checks and fresh independent review remain mandatory.
