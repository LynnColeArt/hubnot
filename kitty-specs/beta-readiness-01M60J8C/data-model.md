# Beta support and recovery concepts

| Concept | Meaning | Authority boundary |
| --- | --- | --- |
| Support contract | Declared supported interfaces, platforms, limitations and evolution rules | Prospective until qualification and beta verdict |
| Compatibility corpus | Released-writer signed records, archive bytes and expected public observations | Test evidence; no fixture private signer is shipped |
| Public recovery set | Code plus explicitly retained collaboration/memory refs and referenced objects | Import still requires validation and explicit trust |
| Private recovery set | Offline protected signer state and explicitly identified local state | Never a public Git object or portable project archive |
| Recovery rehearsal | Public CLI journey restoring data or exclusive signer continuity | Must assert unchanged historical bytes and no inherited roles |
| Qualification observation | Platform/provider/version/scenario/outcome with evidence | Narrow to what actually ran; absence is not failure or success |
| Beta verdict | Review of support contract against outstanding evidence and defects | Not inferred from unit tests or mission paperwork |

Public reconstruction needs no private recovery set. Exclusive signer restoration
requires fencing the former writer and recovering its latest chain; replacement
devices normally get fresh actors. Private audit authority must be deliberately
re-adopted, and interrupted remote writes retain uncertainty until reconciled.
